# 快捷键

Niri 全部键位（源文件 `dotfiles/niri/binds.kdl`，`Mod` = Super）。`Mod+Shift+/` 可在桌面呼出速查表。

## 特殊功能

| 键位 | 功能 |
|------|------|
| `Mod+Shift+/` | 快捷键速查表 |
| `Mod+F1` | 开关输入法（fcitx5） |
| `Mod+F2` | Noctalia 设置 |
| `Mod+P` | 提取窗口信息/取色 |
| `Mod+Escape` | 开关快捷键抑制（给虚拟机/远程全键盘） |

## 应用启动

| 键位 | 功能 |
|------|------|
| `Mod+Return` / `Mod+T` | 终端（foot） |
| `Mod+/` | 临时终端（下拉式） |
| `Mod+B` / `Mod+Alt+B` | Zen 浏览器 / Brave |
| `Mod+E` | 文件管理器（Thunar） |
| `Mod+Alt+O` | opencode（AI 助手） |

## Noctalia 面板

| 键位 | 功能 |
|------|------|
| `Mod+Z` | 程序菜单 |
| `Mod+Space` | 控制中心 |
| `Mod+Alt+W` | 壁纸选择 |
| `Mod+Shift+N` | 通知中心 |
| `Mod+Shift+P` | 电源菜单 |
| `Mod+Alt+V` | 剪贴板历史 |
| `Alt+Tab` | 窗口切换器 |
| `Mod+F10` / `Mod+Shift+F10` | 随机切换壁纸 / 随机下载壁纸 |
| `Mod+Alt+L` / `Mod+Alt+P` | 锁屏 / 锁屏并挂起 |

## 窗口与总览

| 键位 | 功能 |
|------|------|
| `Mod+O` / `Mod+G` | 总览界面 |
| `Mod+Q` | 关闭窗口 |
| `Alt+F4` / `Alt+Shift+F4` | 强杀窗口 / 强杀进程树 |
| `Mod+Shift+E` | 退出 niri |
| `Mod+Tab` / `Mod+Shift+Tab` | 缩略图切换窗口（工作区内） |
| `Mod+grave` | 缩略图切换同类窗口 |

## 焦点与移动

| 键位 | 功能 |
|------|------|
| `Mod+H/J/K/L`（或方向键） | 焦点左/下/上/右 |
| `Mod+Home` / `Mod+End` | 焦点首列 / 尾列 |
| `Mod+Ctrl+H/J/K/L` | 移动列/窗口 |
| `Mod+Shift+H/J/K/L` | 焦点到其他显示器 |
| `Mod+Shift+Ctrl+H/J/K/L` | 移列到其他显示器 |
| `Mod+Shift+Alt+H/J/K/L` | 移工作区到其他显示器 |

## 工作区

| 键位 | 功能 |
|------|------|
| `Mod+U` / `Mod+I` | 上/下一个工作区 |
| `Mod+1-0` | 直达工作区 1-10 |
| `Mod+Ctrl+U/I`（或 `Mod+Ctrl+1-0`） | 移列到工作区 |
| `Mod+Shift+U/I` | 移动整个工作区 |

## 布局

| 键位 | 功能 |
|------|------|
| `Mod+A` / `Mod+D` | 列间吞入/吐出窗口 |
| `Mod+Shift+X` | 列内标签页显示 |
| `Mod+R` / `Mod+Shift+R` | 预设宽度 / 高度 |
| `Mod+F` / `Mod+Alt+F` | 最大化 / 全屏 |
| `Mod+C` | 居中列 |
| `Mod+-` / `Mod+=` | 宽度 ±5%（加 Shift 调高度） |
| `Mod+V` / `Mod+N` | 切换浮动 / 浮动与平铺间切焦点 |

## 截图与媒体

| 键位 | 功能 |
|------|------|
| `Print` / `Ctrl+Print` / `Shift+Print` | 区域 / 窗口 / 显示器截图 |
| `Mod+Shift+S` | 区域截图并标注（satty） |
| `XF86Audio*` | 音量/播放控制 |
| `XF86MonBrightness*` | 亮度 |
